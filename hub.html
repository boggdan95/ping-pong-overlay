Cómo configurar el overlay en OBS Studio

🚀 Inicio Rápido

  1. Abre index.html en tu navegador (Chrome recomendado)
  2. En OBS Studio, agrega una fuente Window Capture (Captura de Ventana)
  3. Selecciona la ventana del navegador con el overlay
  4. Abre control.html en otra pestaña para controlar el marcador
  5. ¡Listo para transmitir! 🎉
